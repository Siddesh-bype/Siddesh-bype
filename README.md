## 🔭 &nbsp;What I'm Working On

- 🛡️ **LLM Prompt Injection Firewall**: Developing an inline middleware proxy that sanitizes user prompts and detects adversarial jailbreak attempts before they reach the model.
- 🚨 **A.I.R.S (Network Intrusion Detection)**: A hybrid ML pipeline trained on network packet telemetry to classify anomalies in real time, paired with an LLM triage layer for incident explanation.
- ☀️ **SolarSense AR**: A mobile application built with Flutter and ARCore that overlays 3D solar geometry on rooftops to model solar power generation on-site.
- ⚙️ **HydroX Digital Twin**: Simulating industrial pump sensor telemetry to perform predictive vibration and temperature anomaly detection.
- ⚡ **Low-Level Socket Server**: A multithreaded client-server chat engine written in pure C++ using POSIX sockets and custom frame protocols.
